# logx

**logx** — CLI утилита для анализа лог-файлов.

Проект является учебным C++ pet-проектом, ориентированным на практику
современного C++, архитектурного проектирования и unit-тестирования.
Приложение анализирует текстовые лог-файлы и агрегирует статистику
по уровням логирования.

Проект разрабатывается под **Linux** и собирается исключительно из терминала
с использованием **CMake**.

---

## Поддерживаемый формат логов

YYYY-MM-DD HH:MM:SS [LEVEL] [MODULE] MESSAGE
Пример:
2026-01-12 10:15:26 [ERROR] [FileSystem] Failed to open file

Поддерживаемые уровни логирования:

- INFO  
- DEBUG  
- WARN  
- ERROR  

---

### Ключевые архитектурные принципы

- разделение ответственности (core / parser / cli)
- отсутствие исключений
- управление ресурсами через RAII
- чистое ядро без зависимостей от I/O, CLI и форматов отчётов

Запуск unit-тестов
